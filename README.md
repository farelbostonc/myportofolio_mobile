# MyPortfolio Mobile

Implementasi Tutorial 08: Basic Flutter, PBP Gasal 2026/2027.

Halaman utama menggunakan StatelessWidget, InfoCard untuk identitas contoh Burhan, dan ItemCard untuk Lihat Proyek, Tambah Proyek, serta Logout. Setiap tombol menampilkan SnackBar; integrasi navigasi dan backend belum termasuk Tutorial 08.

## Menjalankan aplikasi

```sh
flutter pub get
flutter run -d chrome
```

## Pemeriksaan

```sh
flutter analyze
flutter test
```
